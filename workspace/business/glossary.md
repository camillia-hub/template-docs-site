# Business glossary

Use these terms in content and conversations. Add a row when the docs gain a
concept; never invent synonyms.

| Term | Definition |
| --- | --- |
| Reader | The primary audience: an engineer evaluating or operating the product. |
| Docs site | The published MkDocs site; the product's official documentation. |
| Version | A published snapshot of the docs matching a product release (via mike). |
| Tutorial | A lesson that takes a beginner to a working result. |
| How-to guide | Steps to accomplish one specific task. |
| Reference | Factual, exhaustive description (options, flags, API). |
| Explanation | Background and rationale; the "why". |
